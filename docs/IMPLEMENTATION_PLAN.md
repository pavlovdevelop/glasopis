# План за изпълнение

Планът, спрямо който е изграден проектът, с текущия статус на всяка фаза. Поддържа се
актуален, за да може всеки да види какво е завършено, какво е само проверено за типове и какво
остава.

## Избор на библиотеки

| Нужда | Избор | Защо |
| --- | --- | --- |
| Десктоп обвивка | Tauri 2 + React 19 + TypeScript + Vite | малък инсталатор, WebView2 вече на Windows, Rust бекенд |
| Разпознаване на реч | whisper.cpp през `whisper-rs` 0.16 | безплатно, локално, добро за български, без API ключ, статично слинкване |
| Аудио запис | `cpal` 0.17 | поддържано, WASAPI backend, изброяване на устройства |
| Глобални клавишни комбинации | `tauri-plugin-global-shortcut` 2 | събития при натискане *и* отпускане → задържане за говорене |
| Автостарт | `tauri-plugin-autostart` 2 | запис в registry за текущия потребител, без администраторски права |
| Единствен екземпляр | `tauri-plugin-single-instance` 2 | фокусира работещия екземпляр |
| Изтегляне на модели | `reqwest` (blocking, Schannel TLS) + `sha2` | без OpenSSL, без допълнителни build инструменти |
| Windows API-та | `windows` 0.62 | клипборд, SendInput, активен прозорец |

Отхвърлени: всеки облачен API за реч (платен и/или изискващ ключ), Electron (размер), `rdev`
за задържане за говорене (глобален keyboard hook е по-тежък от hotkey plugin-а и изглежда като
keylogger за антивирусния софтуер).

## Какво е проверено, и как

- `cargo test -p glasopis-core` - 52 теста, покриващи обработчика на команди, речника, формата
  и миграцията на настройките, каталога с модели, историята и аудио математиката. Работи на
  Linux и Windows.
- `npm test` - frontend тестове за файловете с преводи, парсера на клавишни комбинации и
  форматирането.
- `cargo clippy --target x86_64-pc-windows-msvc --no-default-features --workspace -- -D warnings`
  - проверява типовете в кода, специфичен за Windows (клипборд, SendInput, трей, клавишни
  комбинации) без C++ toolchain. Това изпълнява Linux частта на CI.
- Windows CI job-ът компилира цялото приложение **с** whisper.cpp и изпълнява бекенд тестовете.
  И трите CI job-а (frontend, core/cross-check, Windows) минават на текущия commit.

## Какво все още изисква истински Windows десктоп

Компилирането не е същото като работещо приложение. Преди да се таг-не `v0.1.0`, ръчният
чеклист в [QA.md](QA.md) трябва да се изпълни на Windows: въвеждане в Notepad, Chrome, Word,
VS Code и терминал; кирилица с двете клавиатурни подредби; автостарт през рестарт; изключване
на микрофон; обработка на грешка при прозорец с повишени права; инсталатор и деинсталатор.
